# HTML learning portfolio — prototype

Early web development exercises by Charles Nkuba, retained to show learning progression in HTML.

[Current professional portfolio](https://charlesnkuba.github.io/) · [Live HTML prototype](https://charlesnkuba.github.io/html-Portfolio/)

## Scope

Movie ranking and birthday invitation pages practise headings, paragraphs, images, lists and relative links. The About and Contact pages connect visitors to my current portfolio and LinkedIn.

This is a learning prototype. It has no application backend, authentication, database or dynamic features. Exercise content should not be treated as a current personal recommendation or real event.

## Run locally

Open `index.html` in a browser, or run:

```sh
python3 -m http.server 8000
```

Visit `http://localhost:8000/`. No package installation or build is required.
